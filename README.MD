Virtual Interest Bank (VIB)

A Python application that helps users make informed investment and borrowing 
decisions. For investments, it identifies options with the highest potential 
returns based on the user's target capital and desired interest rate, along 
with an estimated time to maturity. 

For loans, it recommends offers tailored to the user's needs by evaluating 
the amount they wish to borrow, their target interest rate, and their desired 
repayment period.

Techstack:
Backend - Python
Graphical User Interface - Pygame
Database - OpenData (compiled from ratecompare.co.za & moneytoday.co.za)
